# J-lens 本地预览

当前方向是保留原 AIHOT 排版和色调，以研究图谱、持续动态和讨论为入口，在原布局中增加研究工具。精选、全部动态与主题保留；热点榜、日报、收藏从读者导航移除，没有独立 Observatory 首页或全站换肤。

## 打开检查

- [首页](http://localhost:3000/)、[全部动态](http://localhost:3000/all)、[主题](http://localhost:3000/topics)
- [研究图谱](http://localhost:3000/explore)：节点简要、原文来源、可展开目录与讨论观点
- [Try 小检查](http://localhost:3000/try)、[Investigate 调查计划](http://localhost:3000/investigate)
- [Ouro 阅读资料](http://localhost:3000/items/jlens-ouro)、[后台](http://localhost:3000/admin)

研究分组仅保留图谱入口；独立导读不再展示，旧 `/understand` 返回 302 到 `/explore`，保留 query，原 hash 由浏览器继承；手机底栏现为“精选、研究、我的”。Try 和调查计划也可从原“我的”工具进入。`/research-updates` 跳转至原 `/all`，不另建重复内容流。旧报告及收藏网页跳转 `/all`，卡片和详情不再显示收藏按钮；历史报告及浏览器收藏记录保留。研究模块默认英文，`?lang=zh` 切换中文；原框架导航与工具界面保留中文。

图谱按从左到右的四栏阅读顺序排列，方法改进和循环模型案例分成两支。默认收起多重研究关系，展开后仍保留真实方向和原文依据；来源时间、完整证据卡、覆盖不足分支及历史说明也按需展开。Ouro 的证据路径单独按“来源 → 报告值 → 主张 → 问题 → 未运行提案”排列。左右位置仅表示阅读顺序，不补造继承或实验结果。

图谱内简要直接链接原文，36 条研究目录和 12 条技术观点按需展开；旧双语长导读资产仍保留，不再单独展示。完整路径是：图谱节点简要与原文 → 技术讨论、主张和依据 → 来源曲线 → 算术或可比性检查 → 竞争解释 → 提案保存与导出。个人提案只保存在当前浏览器，版本保留真实父子关系，可导出 JSON/Markdown；它们未经公共审核，也尚未运行实验。来源汇总值重算不等于模型复现。

## 内容与运行状态

阅读索引 `industry/reading-list.json` 现有 36 条资料，其中 34 条进入有原始日期的动态流，Ouro 仓库和旧目录中的层忠实性条目两条无日期资料另有详情入口。评论快照另行保留本轮 API 返回的真实发布时间，不把收集时间填入目录发表时间。只显示摘要与原文链接；未知发表时间保留为空，不编造新近动态或模型评分。来源配置共 40 条：36 个手动外部归属、2 个暂停的 LessWrong RSS 草案、2 个暂停的 X 搜索。来源归属数量不是持续采集数量。用户已决定暂跳过 X，不在聊天中索取凭据。

前轮增加 10 篇原文参考文献确认直接引用 J-lens 的论文、6 条作者报告；本轮再增加 6 篇 arXiv 论文，将目录扩至 36。U-Space 的 LessWrong 导读作为同一研究的关联入口，不重复增加一条独立研究。前轮 16 条与本轮 6 条新增资料均不自动精选；原 12 条有效精选保留。目录数量不是 citation 总数，全球引用总数尚未知。详见 [引用补查](citation-search-2026-10-22.md)、[图谱文献核查](graph-literature-audit-2026-10-22.md) 及网页 `/explore#search-coverage`。本轮原文定位的 28 条关系去重后形成 27 条额外图谱关系；状态仍为机器检查、人工审核待完成、本站未复现。

采集范围限定 J-lens、读出方法、looped LM/Ouro 和直接相关讨论、代码、评测、更正及负结果。保留已有研究记录与纠错依据；评分结构和门槛未改。自动采集、模型调用、推送和 IndexNow 均关闭，尚无自动持续爬取或新模型实验。新增独立的公开 LessWrong 手动评论检查，不启用后台采集阀门或定时任务。

已检查 16 个公开 LessWrong 帖的 30 条评论，选录 12 条具体技术观点，包括 Neel Nanda 对 WorkspaceBench 范围的真实回复。动态详情通过模块 HTTP 端点 `/api/v1/research-discussions?item=ID` 展示对应原帖观点，图谱复用相同 note ID；未检查、检查无选录和读取失败分别显示。分数、作者身份和评论都不自动构成实验验证。来源与父评论语境见 [讨论核查](graph-discussion-audit-2026-10-22.md)。

动态卡片和详情标注 LessWrong、X、GitHub、arXiv 等平台，并保留具体来源名和原文链接；未知平台显示实际域名。平台说明依据原文 URL，不代表证据已核查。公开 v1 API 没有改格式。

复用原采集、去重、审核、发布、RSS/API/MCP 和搜索机制。`REPORTS.enabled=false` 关闭自动报告排程和缺期告警；没有删除历史报告、研究数据或浏览器收藏。研究模块使用原站布局，SSR 通过 HTTP 读取统一 publication 层中的静态研究文档；没有新增 home/shell 框架钩子或数据库表。上游“网站上线、每天出日报”的示例公告也已移除，未编造本站上线历史。

本机 Node 24.22.1、PostgreSQL 17 便携环境在忽略的 `.data/` 中，`.env` 不提交。API 和网页在本机运行；后台使用仅供本地的开发免登录模式。正式部署仍需关闭该模式、配置管理员，并确认条款与隐私模板。

在已配置数据库的环境中，沿用导入脚本：

```sh
node --env-file=.env scripts/seed.ts
node --env-file=.env scripts/import-reading-list.ts
```

重复导入保留已有条目和后台修改；执行导入不代表开启持续采集。已收录 LessWrong 帖可手动检查：

```powershell
.data/node.exe modules/observatory/scripts/collect-discussions.ts --item jlens-bench --out .data/discussion-candidates.json
```

仅写入忽略的 `.data/` 候选及原始响应；重复执行按帖子和评论 ID 更新，保留上一次真实快照。不会调用模型、发布内容或创建定时任务。
