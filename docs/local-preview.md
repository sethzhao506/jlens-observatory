# J-lens 本地预览

当前方向是保留原 AIHOT 排版和色调，以持续研究动态和讨论为主，在原布局中增加研究工具。精选、全部动态与主题保留；热点榜、日报、收藏从读者导航移除，没有独立 Observatory 首页或全站换肤。

## 打开检查

- [首页](http://localhost:3000/)、[全部动态](http://localhost:3000/all)、[主题](http://localhost:3000/topics)
- [研究导读](http://localhost:3000/understand)、[演化图](http://localhost:3000/explore)
- [Try 小检查](http://localhost:3000/try)、[Investigate 调查计划](http://localhost:3000/investigate)
- [Ouro 阅读资料](http://localhost:3000/items/jlens-ouro)、[后台](http://localhost:3000/admin)

导读、图谱属于研究分组；手机底栏现为“精选、研究、我的”。Try 和调查计划也可从原“我的”工具进入。`/research-updates` 跳转至原 `/all`，不另建重复内容流。旧报告及收藏网页跳转 `/all`，卡片和详情不再显示收藏按钮；历史报告及浏览器收藏记录保留。研究模块默认英文，`?lang=zh` 切换中文；原框架导航与工具界面保留中文。

图谱按从左到右的四栏阅读顺序排列，方法改进和循环模型案例分成两支。默认收起多重研究关系，展开后仍保留真实方向和原文依据；来源时间、完整证据卡、覆盖不足分支及历史说明也按需展开。Ouro 的证据路径单独按“来源 → 报告值 → 主张 → 问题 → 未运行提案”排列。左右位置仅表示阅读顺序，不补造继承或实验结果。

完整路径是：导读 → 图谱中的主张和原文 → 来源曲线 → 算术或可比性检查 → 竞争解释 → 提案保存与导出。个人提案只保存在当前浏览器，版本保留真实父子关系，可导出 JSON/Markdown；它们未经公共审核，也尚未运行实验。来源汇总值重算不等于模型复现。

## 内容与运行状态

阅读索引 `industry/reading-list.json` 现有 30 条资料，其中 28 条进入有原始日期的动态流，Ouro 仓库和层忠实性评论两条无日期资料另有详情入口。只显示摘要与原文链接；未知发表时间保留为空，不编造新近动态或模型评分。来源配置共 34 条：30 个手动外部归属、2 个暂停的 LessWrong RSS 草案、2 个暂停的 X 搜索。来源归属数量不是持续采集数量。用户已决定暂跳过 X，不在聊天中索取凭据。

本轮增加 10 篇原文参考文献确认直接引用 J-lens 的论文、6 条作者报告。U-Space 的 LessWrong 导读作为同一研究的关联入口，不重复增加一条独立研究。新增 16 条不自动精选；原 12 条有效精选保留。目录数量不是 citation 总数，全球引用总数尚未知。详见 [引用补查](citation-search-2026-10-22.md) 及网页 `/understand#search-coverage`。

采集范围限定 J-lens、读出方法、looped LM/Ouro 和直接相关讨论、代码、评测、更正及负结果。保留已有研究记录与纠错依据；评分结构和门槛未改。自动采集、模型调用、推送和 IndexNow 均关闭，尚无持续爬取或新模型实验。

动态卡片和详情标注 LessWrong、X、GitHub、arXiv 等平台，并保留具体来源名和原文链接；未知平台显示实际域名。平台说明依据原文 URL，不代表证据已核查。公开 v1 API 没有改格式。

复用原采集、去重、审核、发布、RSS/API/MCP 和搜索机制。`REPORTS.enabled=false` 关闭自动报告排程和缺期告警；没有删除历史报告、研究数据或浏览器收藏。研究模块使用原站布局，SSR 通过 HTTP 读取统一 publication 层中的静态研究文档；没有新增 home/shell 框架钩子或数据库表。上游“网站上线、每天出日报”的示例公告也已移除，未编造本站上线历史。

本机 Node 24.22.1、PostgreSQL 17 便携环境在忽略的 `.data/` 中，`.env` 不提交。API 和网页在本机运行；后台使用仅供本地的开发免登录模式。正式部署仍需关闭该模式、配置管理员，并确认条款与隐私模板。

在已配置数据库的环境中，沿用导入脚本：

```sh
node --env-file=.env scripts/seed.ts
node --env-file=.env scripts/import-reading-list.ts
```

重复导入保留已有条目和后台修改；执行导入不代表开启持续采集。
